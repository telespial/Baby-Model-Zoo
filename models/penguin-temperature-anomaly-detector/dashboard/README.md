# FRDM-MCXC162 temperature dashboard

The local Web Serial dashboard supports macOS, Windows, and Linux. From the
repository root, run:

```sh
node scripts/serve-dashboard.mjs
```

The server opens <http://localhost:4173> in the default browser. Use a current
desktop Chrome or Edge build, select **Connect board**, and choose the MCU-Link
serial port.

Complete installation, connection, SW2/SW3, LED, training-window, recording,
playback, export, and troubleshooting instructions are in the
[FRDM-MCXC162 project guide](../README.md).
